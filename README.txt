OMA Seguros - Borrador Web v2

Contenido:
- index.html
- styles.css
- app.js
- assets/oma-logo.png

Esta versión es un demo estático para presentación.
Registro, login y cotizaciones usan localStorage del navegador.
No debe usarse como autenticación de producción.

Para producción se recomienda:
- Backend seguro (PHP/Laravel, Node, etc.)
- Base de datos
- Hash de contraseñas
- Recuperación de contraseña
- Verificación de correo
- Roles de usuario y administrador
- Protección CSRF/XSS y validación servidor
- Política de privacidad y consentimiento de datos
- Carga segura de documentos
